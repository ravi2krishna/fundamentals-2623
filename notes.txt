Class - 1
==========

    -> Application 

        -> An Application Is a Software Program Designed To Perform A "TASK"

            -> https://www.myntra.com - Helps Me Buy Products On Internet (Task) 

            -> https://www.flipkart.com - Helps Me Buy Products On Internet (Task) 

            -> https://www.amazon.in - Helps Me Buy Products On Internet (Task) 

            -> NOTE: All the Above are Ecommerce Applications 

            
            -> http://instagram.com - Helps Me Contact My Friends / Send Some Msg (Task) 

            -> http://facebook.com - Helps Me Contact My Friends / Send Some Msg (Task) 

            -> NOTE: All the Above are Social Media Applications 


    -> Application Types 

        -> Desktop Applications 

        -> Web Applications 

        -> Mobile Applications 

        -> Enterprise Applications 

        -> etc 


    -> Desktop Applications 

        -> Desktop Applications Designed To Run On "SINGLE MACHINE"

            -> Only One User Can Access At A Time 

            -> Installed On Desktops / Laptops 

            -> MS Suite (MS Office) 

            -> NOTE: Most Of The Desktop Application, can work without Internet


        
        -> Web Applications

            -> An Web Application Uses Internet and Is Accessed Using Browser 

            -> Multiple Users Can Simultaneously Access At A Time 

                -> https://www.myntra.com - user1 (5 products)

                -> https://www.myntra.com - user2 (1 products)

            -> We Don't Need To Install Web Applications 

            -> Web Applications Are Deployed On "SERVERS"

                -> https://upload.wikimedia.org/wikipedia/commons/c/c9/Client-server-model.svg

            -> Every Web Application Uses Client - Server Architecture 

                -> Client (Browser) - Server (Physical Server - Web Server)

                -> Client (Mobile) - Server (Cloud Server - Database Server)

                -> Client (Tab) - Server (Virtual Server - Application Server)




Class - 2
==========

    -> Web Applications use Client - Server Architecture 

        -> Static Applications 

            -> Static: Fixed / Doesn't Change 

            -> Static Application, Have Fixed Data / Content For Any User 

            -> https://www.edifynuva.com/

                -> Multiple Users Access Application With Same Data 


        -> Dynamic Applications 

            -> Dynamic: Not Fixed / Does Change 

            -> Dynamic Application, Has Different Data / Content For Different Users 

            -> https://gmail.com/ 

                -> Multiple Users Have Different Inbox Mails 

                    -> user1 - 200 emails 

                    -> user2 - 20 emails 

                    -> user2 - 2000 emails 

    
    -> Mobile Applications

        -> Mobile Applications are Installed On Mobiles Devices / Tablets 

        -> Installed From Playstore / Appstore 

        -> Mobile Applications Utilizes, Hardware From Mobile Devices 

            -> Mobile Phone Has GPS: Used For Navigation(Google Maps)

            -> Mobile Phone Has Camera: Used For Taking Videos(Camera App)

            -> Mobile Phone Has Antenna: Used For Making Calls(Phone App)


    -> NOTE: Mostly We Work With Dynamic Applications 

        -> Because Of Following 

            -> https://en.wikipedia.org/wiki/Programming_languages_used_in_most_popular_websites


        -> One thing the most visited websites have in common is that they are dynamic websites/Applications

        -> Their development typically involves 
        
            -> server-side coding 
            
            -> client-side coding and 
            
            -> database technology

        -> The Above Forms The Basis For Three Tier Architecture / Multi Tier Architecture 


    
    
    -> Frontend Technologies

        -> Application Layer That Shows "User Interface" (Look & Feel)

        -> Takes Input & Displays Output 

        -> Technologies: HTML / CSS / JS(Reactjs)

            -> HTML - Structure / Skeleton To Your Site 

            -> CSS - Add Beautification To Your Site 

            -> Javascript - Adds Actions To Your Site

            -> https://miro.medium.com/v2/resize:fit:1400/0*pNREGiTjwWD4EFKC

        -> Application Layer That Handle "Business Logics"
